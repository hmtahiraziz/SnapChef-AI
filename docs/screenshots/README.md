## Tips

- Prefer PNG or JPEG.
- Capture on a real device or emulator at a consistent width (e.g. iPhone 14 / Pixel).
- Portrait orientation works best for the SRS.
- You may use `.jpg` instead of `.png` if you also update the image links in the SRS.
